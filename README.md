# Dimension Graffiti

A Spider-Verse rooftop game for 1 to 10 players. Swing Brooklyn rooftops, paint the city your color, then race a glitch portal.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## How to play

- **Play now** starts a match on this device. Empty slots can be filled with bots.
- **Create room** hosts a match and shows a code. Friends join with that code, and the host starts the match.
- Modes are graffiti only, race only, or both in sequence.
- Heat is Chill, Street, or Spider-Verse.

## Controls

- A / D move
- W or Space jump
- Hold click to web
- E or Shift spray

On-screen buttons cover the same actions on touch.
